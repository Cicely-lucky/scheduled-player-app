# 第 1 章 产品简介

小云闹钟是一款面向学习与自律场景的定时唤醒工具。

它能够在指定时间自动打开某个网址或播放本地音视频文件，帮助用户建立稳定的作息节奏。

与传统闹钟不同，小云闹钟的核心是「内容唤醒」：到点后不是响铃，而是直接拉起你预设的学习内容。

典型使用场景包括：

- 早晨到点自动播放英语听力或晨读音频；

- 学习时段定时打开 B站、慕课等在线课程；
──── 第 1 页 / 共 19 页 ────

- 午休或睡前自动播放冥想、白噪音音频；

- 番茄工作法中，定时响起专注提示并打开计时页面。

本应用不依赖账号登录、不上传用户数据，所有任务均保存在手机本地。

# 第 8 章 权限设置

![图 8-1 权限设置说明](C:/Users/jiayanli/WorkBuddy/2026-08-27-09-36-38/scheduled-player-app/.workbuddy/软著材料/screenshots/perm.png)
*图 8-1 权限设置说明*

由于 Android 系统限制，到点自动打开链接或播放需要多项后台权限。首页顶部会根据权限状态弹出黄色提示条。

## 8.1 必须开启的权限

| 权限 | 作用 | 设置路径 |
| --- | --- | --- |
| 悬浮窗 | 允许应用在其他应用上层显示，从后台拉起播放 | 设置 → 应用 → 小云闹钟 → 权限管理 → 悬浮窗 |
| 后台弹出界面 | MIUI 专属，允许后台启动 Activity | 权限管理 → 后台弹出界面 |
| 锁屏显示 | 锁屏时能够亮屏并弹出播放界面 | 权限管理 → 锁屏显示 |
| 省电策略 → 无限制 | 避免系统冻结后台进程导致闹钟失效 | 设置 → 应用 → 小云闹钟 → 省电策略 |
| 自启动 | 应用被杀后仍能响应闹钟广播 | 设置 → 应用 → 小云闹钟 → 自启动 |

## 8.2 不同品牌手机差异

- **小米 / Redmi（MIUI / HyperOS）**：需要开启后台弹出界面、锁屏显示、自启动、省电策略无限制。

- **华为 / 荣耀（EMUI / HarmonyOS）**：重点设置「电池优化 → 不允许」和「应用启动管理 → 手动管理 → 允许后台活动」。

- **OPPO / vivo / 一加（ColorOS / OriginOS）**：设置「允许后台高耗电」「允许自启动」「锁屏后保持运行」。

- **Pixel / 原生 Android**：通常只需开启悬浮窗和省电策略无限制。

## 8.3 快速配置步骤

1. 首次打开应用，若顶部出现「悬浮窗权限未开启」提示条，点击「去开启」。

2. 进入系统权限页，开启「悬浮窗」。

3. 返回应用，若仍提示，再点击提示条进入「应用详情」开启其余权限。

4. 小米手机用户需特别注意：除悬浮窗外，还要手动开启「后台弹出界面」「锁屏显示」「自启动」和「省电策略 → 无限制」。

# 第 10 章 常见问题与使用贴士

## 10.1 到点后没有反应怎么办？

按顺序检查：

1. 任务是否已启用（详情页开关是否为蓝色）。

2. 频次与今天是否匹配（例如只在周五设置的任务，周四不会触发）。

3. 是否已开启悬浮窗、后台弹出界面、锁屏显示、自启动、省电策略无限制。

4. 手机是否处于关机或飞行模式（闹钟依赖系统时间）。
──── 第 14 页 / 共 19 页 ────

5. 是否刚重装应用（权限和任务数据均被重置）。

## 10.2 播放一次后就不再自动播放了？

- 多为系统杀掉后台进程导致。请开启自启动和省电策略无限制。

- V1.0.0 已做双链调度和原生自愈加固，即使 Dart 后台链被杀，原生闹钟链也会尝试自注册下一次。

- 如仍出现，请检查系统是否有「省电助手」「睡眠模式」等额外限制。

## 10.3 可以打开其他 App 的链接吗？

- http/https 通用链接均可，系统会交给浏览器或对应 App 处理。

- 部分 App 私有 Scheme 深链受系统包可见性限制，可能无法直达，会弹出选择框。

## 10.4 数据会上传吗？

- 不会。所有任务数据仅保存在本机应用沙箱，应用不集成统计 SDK，不发起网络请求。

## 10.5 卸载后任务还在吗？

- 不在。任务数据随应用沙箱一起删除，卸载前请自行记录重要任务。

## 10.6 支持 iOS 吗？

- 当前版本仅支持 Android。核心调度依赖 Android 专属能力（AlarmManager、前台服务、BAL 豁免），iOS 需另外实现。

# 第 13 章 升级、卸载与重装

## 13.1 升级应用

- 同一包名的新版本 APK 可直接覆盖安装，任务数据会保留。

- 若包名发生变化（如从旧版 com.example.scheduled_player_app 迁移到新版 com.cici.scheduledplayer），需先卸载旧版再安装新版。

- 覆盖安装后建议重新检查权限设置是否仍有效。

## 13.2 卸载影响

- 卸载应用会同时删除所有任务数据，无法恢复。

- 已注册的系统闹钟会被清除。

- 如有重要任务，请在卸载前截图或手动记录。

## 13.3 重装后配置

- 重装应用后，所有权限会被系统重置为零。
──── 第 18 页 / 共 19 页 ────

- 必须重新走一遍权限配置流程（悬浮窗、后台弹出、锁屏显示、自启动、省电策略）。

- 任务也需要重新创建。
